# 🔐 Super Safe Password Generator

A sleek, full-screen password generator app built with Python and Tkinter. 

## 🚀 How to Run It

1. Make sure you have Python installed on your computer.
2. Download the `password maker test 1.0.py` file from this repository.
3. Open your Terminal (Mac) or Command Prompt (Windows).
4. Run the app using this command:
   ```bash
   python3 "password maker test 1.0.py"
   ```

## 🎮 Controls
* Press **`Escape`** on your keyboard to exit full-screen mode.
* Click **`Copy to Clipboard`** to instantly save your new password.
